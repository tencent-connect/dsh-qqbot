# QQ 默认配置、对话设置与消息记录

QQ 使用独立的群聊和私聊导航。点击群或联系人打开 DSH 原生聊天，展开箭头查看它的历史 Session，默认显示最近五条。历史不再单独占用设置页面。

## 配置新接入的对话

在 QQ 机器人全局设置中打开**新对话默认设置**。这里配置之后首次接入的群聊和私聊使用的 Agent、权限、模型、额外提示词和工作目录。

默认设置会复制给新对话。之后修改默认值不会修改已经接入的对话。只被发现、尚未授权的群或联系人，在首次接入时采用当时的默认设置。

Agent 预设使用 DSH 已安装的组合。执行权限与 Agent 预设分别选择。权限模式沿用 DSH 的“仅可查看”“工作区内修改”和“完全权限”。原生模式采用所选 Agent 实际拥有的工具与原生沙箱、审批规则。只读不表示只能读取工作区。

选择**自定义工具**后，再选择基础权限和需要保留的工具。可以搜索、按分类选择、清空当前搜索结果。所选工具仍受 Agent 实际工具集和基础权限限制。勾选不存在于 Agent 的工具不会给它新增能力。

## 调整某个群或联系人

在原生会话的**QQ 机器人会话设置**中编辑接收开关、QQ 备注、执行权限、自定义工具、当前群聊或私聊的补充提示词和消息保存开关。消息记录跨 Session 展示，默认不自动删除，也可手动清空；已有显式保留期限继续生效。

当前模型和推理强度在原生输入框调整；Agent 预设与工作区从该联系人或群的菜单选择**新建会话**时确定。新对话默认设置仍可配置这些初始值，当前对话的 QQ 设置不重复提供它们。输入框的同一个权限菜单提供原生模式，第四项为**自定义工具**。选择自定义保留当前原生基础权限，工具清单仍在**QQ 机器人会话设置**中编辑；可用能力取 Agent 实际工具、原生权限和所选工具的交集。仅修改 QQ 备注或提示词不会重设模型、预设、工作区或原生权限。

会话设置在空闲时保存。补充提示词保存后在后续组装提示词时生效，无需新建 Session。群聊与私聊补充提示词各最多 80,000 个字符；对话设置只显示当前场景的提示词。

停用接收会阻止新入站处理和 QQ 任务，不删除已有记录或 DSH 历史。群聊仍默认只有 @ 机器人时回复。QQ 平台没有推送的消息不会出现在记录中。

本分支已有试用数据中的高级授权约束在导入后、尚未重新保存 QQ 设置时保留；它们不是上游 0.5.5 的配置字段。重新保存会按本版原生权限与工具模式生成策略，不保留旧版 `readRoots`、`writeRoots` 和网络域名列表；自定义模式中仍选中的 `ask` 工具保留审批标记。依赖旧版限制时请先核对[升级说明](./upgrading-from-0.5.5.md)。保存工具选择只作用于当前对话。原生权限或设置版本在编辑期间发生变化时，需核对最新值后重新保存。

保存时检查配置版本。其他页面或手机命令已修改配置时，界面保留草稿并提示冲突。保存失败不会报告成功。

原生输入框继续提供当前模型、权限、附件与输入能力。QQ 设置不替换原生输入路径。网页回答只在网页显示；发送到 QQ 需要对已完成回答执行显式发送。

## 使用斜杠命令

所有 QQ 斜杠命令仅全局超管可用，包括帮助、查询和停止命令。全局设置中的超管名单支持配对码添加、改名和移除；网页命令清单与 QQ 帮助都来自服务端命令注册表。

超管在群里按 @ 规则发送命令，私聊直接发送命令，仍受对话的访问规则、工具与资源限制。非超管调用任何命令都会被拒绝，群管理员身份不会自动获得超管权限。原生 DSH 网页命令不受 QQ 身份限制，审批与提问按钮继续使用各自的权限规则。

## 保留与清空 QQ 消息

开启**保存 QQ 消息**后，每个群或联系人的收发记录跨 Session 连续保存，默认不按条数或天数自动删除；已有显式期限仍按原配置执行。投递状态更新不计作新消息、不刷新顺序。关闭保存只停止新增 QQ 正文，已有记录保留；从旧格式迁移的关闭状态不会自动开启。未授权或停用的对话不保存新正文。

上游 `historyLimit` 默认 10，限制群上下文的内存缓冲，不是持久记录的保留条数。本版沿用该配置，不额外设置收发正文的强制条数上限。

需要时点**清空消息记录**，清除 QQ 记录正文及其查询副本。清空时保留消息身份、正文哈希、投递状态、分段回执和旧 operation 幂等元数据，防止旧操作重发。

记录保留与原生会话轮换分别管理。新接入对话的原生会话默认满七天或 1,000 条 QQ 消息后自动换新并保留历史；旧格式迁移的对话不自动开启轮换。DSH 原生 Session 中实际使用过的提问、背景、回答与工具结果独立保留，QQ 记录淘汰或清空不删除它们。

## 查看收发记录与历史

**消息记录**跨 Session 连续展示，收到的消息在左，机器人出站在右。命令、自动回复和网页显式发送标明来源。仅网页回答不伪造成 QQ 出站消息。此页只有回看、搜索和来源定位，没有第二个输入框。

“QQ 接口已接受”不代表送达或已读。失败显示实际错误，结果未知不会自动重发。群消息的被动回复窗口为五分钟，网页浏览和查询不延长窗口。发送确认页保留窗口提示，消息记录页不显示主动发送说明；是否允许主动发送仍取决于 QQ 平台授权。

左侧展开群或联系人查看历史。打开历史不会恢复接收映射、重放输入或发送旧回答。原生空白 Session 可能使用宿主欢迎页而暂不显示会话标签；这时仍可从左侧该对话菜单进入设置。

## 数据兼容

插件维护 QQ 收发账本，DSH 维护原生执行历史。新默认配置、对话配置和记录规则随账户目录持久保存，不需要修改 DSH 宿主或部署额外服务。

格式升级和恢复不会启动模型或外发消息，也不因正文条数超过 1,000 而清理记录。升级前保存同一时点的插件数据与原生 Session 存储，详见[从 0.5.5 升级](./upgrading-from-0.5.5.md)。不要恢复旧发送账本后继续发送，否则会丢失已经执行操作的防重信息。旧版插件不能安全写入新格式时，只允许只读导出后再决定回退。
