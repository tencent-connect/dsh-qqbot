# QQ 默认配置、对话设置与消息记录

QQ 使用独立的群聊和私聊导航。点击群或联系人打开 DSH 原生聊天，展开箭头查看它的历史 Session，默认显示最近五条。历史不再单独占用设置页面。

## 配置新接入的对话

在 QQ 机器人全局设置中打开**新对话默认设置**。这里配置之后首次接入的群聊和私聊使用的 Agent、权限、模型、额外提示词、工作目录和斜杠命令开关。

默认设置会复制给新对话。之后修改默认值不会修改已经接入的对话。只被发现、尚未授权的群或联系人，在首次接入时采用当时的默认设置。

Agent 预设使用 DSH 已安装的组合。执行权限与 Agent 预设分别选择。权限模式沿用 DSH 的“仅可查看”“工作区内修改”和“完全权限”。原生模式采用所选 Agent 实际拥有的工具与原生沙箱、审批规则。只读不表示只能读取工作区。

选择**自定义工具**后，再选择基础权限和需要保留的工具。可以搜索、按分类选择、清空当前搜索结果。所选工具仍受 Agent 实际工具集和基础权限限制。勾选不存在于 Agent 的工具不会给它新增能力。

## 调整某个群或联系人

在原生会话的**QQ 机器人会话设置**中编辑接收开关、备注与 Agent 配置；消息记录默认全部保留，可在面板里手动清空。此处使用与全局相同的配置表单。

模型与权限在空闲时应用。额外提示词、Agent 预设和工作目录作为之后新建 QQ Session 的配置保存。当前 Session 保留原上下文与原目录。需要开始使用这些新设置时，从该联系人或群的菜单选择**新建会话**。

停用接收会阻止新入站处理和 QQ 任务，不删除已有记录或 DSH 历史。群聊仍默认只有 @ 机器人时回复。QQ 平台没有推送的消息不会出现在记录中。

旧对话的工具审批、目录范围和其他授权限制不会在升级时被取消。页面会显示旧限制仍在生效。明确确认切换后，才改用新的原生或自定义工具规则。此操作不会改变其他对话。

保存时检查配置版本。其他页面或手机命令已修改配置时，界面保留草稿并提示冲突。保存失败不会报告成功。

原生输入框继续提供当前模型、权限、附件与输入能力。QQ 设置不替换原生输入路径。网页回答只在网页显示；发送到 QQ 需要对已完成回答执行显式发送。

## 使用斜杠命令

开启斜杠命令后，可以通过 QQ 使用现有的帮助、状态、模型、预设、新会话和停止命令。群聊命令需要符合 @ 规则和管理权限。关闭后，命令不启动 Agent，并明确提示命令已关闭。

机器人所有者名单也用于超级管理员。所有者可以在关闭斜杠命令的对话中使用命令，但不能绕过该对话的工具与资源限制。群管理员身份不会自动获得机器人管理权。

## 保存多少条 QQ 消息

QQ 实际收到或提交发送的消息默认全部保留、不自动清理。需要时在会话设置的「消息记录」里点「清空消息记录」手动清除：只清记录正文，保留消息标识用于去重。

记录保留与原生会话轮换是两件事：原生会话默认满七天或 1,000 条消息后自动换新（保留历史），而消息记录本身不自动按条数或天数淘汰。

超过数量限制后清理旧正文及其查询副本，仍保留去重和发送防重所需的标识、摘要及状态。未决投递保留必要数据。DSH 原生 Session 中实际使用过的提问、背景、回答与工具结果单独保留，QQ 记录清理不删除它们。

## 查看收发记录与历史

**消息记录**跨 Session 连续展示，收到的消息在左，机器人出站在右。命令、自动回复和网页显式发送标明来源。仅网页回答不伪造成 QQ 出站消息。此页只有回看、搜索和来源定位，没有第二个输入框。

“QQ 接口已接受”不代表送达或已读。失败显示实际错误，结果未知不会自动重发。群消息的被动回复窗口为五分钟，网页浏览和查询不延长窗口。过期时界面提示主动发送是否可用仍取决于 QQ 平台授权。

左侧展开群或联系人查看历史。打开历史不会恢复接收映射、重放输入或发送旧回答。原生空白 Session 可能使用宿主欢迎页而暂不显示会话标签；这时仍可从左侧该对话菜单进入设置。

## 数据兼容

插件维护 QQ 收发账本，DSH 维护原生执行历史。新默认配置、对话配置和记录规则随账户目录持久保存，不需要修改 DSH 宿主或部署额外服务。

格式升级和恢复不会启动模型或外发消息。不要恢复旧发送账本后继续发送，否则会丢失已经执行操作的防重信息。旧版插件不能安全写入新格式时，只允许只读导出后再决定回退。
