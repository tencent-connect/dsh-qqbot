# 从 0.5.5 升级

本说明针对上游 `a4a01fa` 的数据格式。新版使用未修改 DSH 的公开接口，但提高了最低运行环境要求，并调整 QQ 出站和命令权限；不是所有旧安装的直接替换版本。不会仅因 QQ 记录超过 1,000 条而删除正文。

## 准备与版本

运行 DSH 的 Node 需要 22.19 及之后的 22.x，或 24 及之后的版本。Node 20、23 不受支持。客户端与控制器的依赖要求见 `package.json`；旧版验证过的 DSH 0.1.0-rc.8、0.2.0-rc.2 不沿用兼容结论。不要忽略依赖安装错误强行启用。

停止旧插件写入后，保存同一时点的插件配置、插件数据及关联 DSH Session 存储与索引。默认数据目录仍为 `~/.dsh-qqbot`，隔离实例使用 `QQBOT_DATA_DIR`；改成空目录不会自动搬迁旧数据。备份含身份与会话内容，应仅允许本机用户访问。

## 迁移行为

- 按账号、群聊、私聊身份精确导入旧 `model-prefs.json` 中的 Session ID、模型和预设。没有 Session 的模型或预设偏好同样保留，不虚构 Session。
- 相对工作目录按旧宿主启动目录解析，不改成相对于插件数据目录。
- 全部投影通过校验后一次原子提交，完成标记与配置一并保存。重复启动不覆盖升级后的编辑，旧文件保留原字节。
- 首次将真实旧数据导入全新目录时，旧私聊白名单中已有群管理和审批权的身份导入超管。已有目录和已撤销的超管不重新导入。旧开放访问模式不等于所有人都是超管，需明确配置控制者和审批者。
- 从旧格式导入的对话不新增 QQ 正文保存、不自动换新，已有 `recording.enabled=false` 继续保持。已有新版目录的保存配置和显式期限保留，不新增条数淘汰或默认七天清理。新接入对话的 QQ 记录默认不自动删除。
- 手动清空或已有显式期限只清 QQ 账本正文及其查询副本；消息身份、正文哈希、投递状态、分段回执和旧 operation 幂等元数据保留，不因清理而重新发送。DSH 原生 Session 历史独立保留。

旧版未保存的普通群消息无法补回。旧偏好通常只有最新 Session ID，不按标题猜测其他历史归属；原生历史仍可在 DSH 查看。

上游 `historyLimit` 默认 10，仅用于群上下文的内存缓冲。上游没有七天持久正文清理或 1,000 条持久记录上限，本版不新增这些默认清理行为。

## 受阻与恢复

旧 `/new` 可能仅预留 ID，尚未创建 Session。它与原会话存储缺失无法仅凭旧偏好区分。新版保留关联并提示恢复存储，或由用户明确 `/new`。明确新建使用新 ID，旧关联保留，不在旧 ID 下创建空历史。

旧文件损坏、不可读或迁移写入失败时，显示迁移受阻。不会覆盖原文件、猜测映射、启动模型或发送历史。恢复文件后重启重试。已完成迁移的可信新目录不再依赖旧偏好文件可解析。

## 不兼容的行为变化

| 能力 | 新版行为 |
| --- | --- |
| `/bot-me` 与其他旧命令 | 保留，所有 QQ 斜杠命令仅全局超管可用，包括帮助、查询和停止命令。帮助与网页从命令定义生成。 |
| 模型与预设 reset | 使用 QQ 网页默认，未指定时继承 DSH。模型保留上下文，预设通过新建应用。 |
| QQ 会话设置 | 模型与推理强度在原生输入框调整，Agent 预设与工作区在新建会话入口选择。QQ 设置保留接收、备注、补充提示词和记录开关。 |
| 执行权限与工具 | 输入框的同一个权限菜单提供原生模式和第四项“自定义工具”。选择自定义保留当前原生基础权限，工具清单仍在 QQ 会话设置中编辑，并与 Agent 实际工具及原生权限取交集。仅改备注或提示词不重设模型、预设、工作区或原生权限。 |
| 本分支此前试用的高级授权约束 | 已有试用目录导入后未重新保存 QQ 设置时保留。这些字段不属于上游 0.5.5 的配置。重新保存会按本版原生权限和工具模式重建策略，不保留旧版 `readRoots`、`writeRoots` 和网络域名列表；自定义模式中仍选中的 `ask` 工具保留审批标记。依赖这些旧限制的部署应先核对策略差异。 |
| QQ 正文记录 | 跨 Session 展示，默认不按条数或天数自动删除；已有显式期限继续生效。手动清空不删除原生 Session 历史或发送防重元数据。 |
| 自动 QQ 回复 | 只发送经原生日志确认的纯 QQ 轮次。网页输入、Steer 与混合来源不自动外发。 |
| QQ 流式、工具过程、文件发送 | 本版不提供。`streaming`、`showToolResults`、`sendFile.sendPresentedFiles` 仅保留旧配置解析。 |
| 被动回复过期、超额 | 显示失败或未知，不自动改用其他来源或主动推送重试。 |
| QQ 命令与按钮权限 | QQ 命令统一使用全局超管名单；原生 DSH 网页命令不受 QQ 身份限制。审批与提问按钮继续使用各自的权限规则。旧开放模式下任意成员的管理能力不保留。 |

需要旧流式或文件能力的部署应继续使用旧版，等待这些能力完成来源与权限约束后的独立实现。本版不承诺上述能力无损替换。

## 回退

换回旧代码不等于完整数据回退。旧版读不到新版全部会话设置与记录。需要恢复匹配的配置及存储快照，另行保留升级期间新增数据。不要让旧、新插件同时写同一目录；恢复快照也不意味着保留全部升级后数据的无损降级。
