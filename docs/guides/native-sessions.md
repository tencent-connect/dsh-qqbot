# QQ 会话与 DSH 原生聊天

本开发版仅使用未修改 DSH 的公开扩展接口。QQ 会话使用独立左侧导航、DSH 主聊天页和原生输入框，不需要定制宿主。共享记忆不在本版范围内。

## 打开与管理会话

每群共享一个当前 Session，私聊按联系人独立。点击「QQ 机器人」进入独立 QQ 左栏，按群聊与私聊分组。群或联系人行代表当前会话，点击名称直接打开；不再额外显示重复的当前 Session 子项。有历史时，箭头展开最近 5 条历史会话，更多历史按需展开。搜索匹配对话名称、备注和会话标题。未授权或尚无会话的项目先打开管理抽屉，不因浏览而启动模型。

QQ 左栏与普通工作区树使用独立导航模式，打开原生聊天页仍保留 QQ 左栏。「返回工作区」、原生新建会话或切换其他主面板会恢复普通工作区导航。目录轮询不改变选中会话、展开状态或历史阅读位置。

联系人第二行显示当前 Session 的有效标题与工作区短名称，与联系人重复的默认标题省略。历史行显示对应 Session 的标题及自身工作区，完整目录放在悬浮提示中。当前会话与历史只保留一个选中态。联系人菜单分别提供当前会话操作和 QQ 对话设置；历史行的重命名定位对应历史会话，工作区入口明确表示新建当前会话。工作区不作为 QQ 列表的父级。Session 重命名与 QQ 联系人备注分别保存；平台名称刷新不会覆盖本地备注。没有可靠名称时显示类型与缩短标识，不把群成员昵称当群名。

当前 stock Host 没有公开的渠道 Session 列表排除接口。底层仍为原生 Session，回到普通工作区树后可能再次看到 QQ Session。本版明确保留此限制，不通过伪装归档、子 Agent 或 CSS 隐藏它们。

主聊天页复用原生模型、推理等级、权限及输入控件。轨迹右侧的 QQ 机器人会话设置只展示配置和消息记录，历史位于左侧群或联系人子树。历史 Session 保持宿主的原生行为；QQ 当前路由只由插件的当前 Session 关联决定。浏览或在旧 Session 中输入不会把它重新变成 QQ 当前会话。

工作区选择指向 DSH 已登记的实际目录。改变 QQ 工作区或 Agent 预设会创建新的当前 Session，保留旧历史与工作区配置；不修改已创建 Session 的工作目录，不原地替换 Agent 组合。模型切换保留上下文，不改变宿主默认值。

## QQ 与网页输入

QQ 提问通过原生 `followup` 进入同一 Agent Inbox，网页继续使用 DSH 原生输入路径。插件只为 QQ 入站准备和投递排序，不替换宿主输入服务。

网页问题只在网页回复，内容进入此 Session 的后续共享上下文。这不是内容保密模式。需要私密分析时，另建普通 DSH Session。

自动发送 QQ 必须同时满足以下条件。

- 原始 QQ 请求已持久保存，原生 Inbox 和实际输入能证明来源与完整内容。
- 本轮只有一个未被修改的 QQ 开始输入，未混入网页 Steer 或未经验证的人类回答。
- 轮次成功完成，最终正文及输入已确认持久化。
- 发送时当前对话、Session 代次与权限仍有效。

排队项被编辑后再恢复原文、移动至 Steer、混合多个 QQ 输入或缺少来源证据时，整个轮次不自动外发。当前 QQ Session 中符合条件的已完成回答可以通过“发送到 QQ”预览目标与正文后显式发送；历史 Session 不提供此动作。

本版 QQ 自动发送最终正文。流式内容、推理、工具过程和生成文件仅在 DSH 展示。旧 `streaming`、`showToolResults` 和文件发送配置字段保留兼容，不代表这些路径仍会外发。

投递先保存操作标识与分段状态，同一对话依次发送。结果区分待发送、发送中、接口接受、失败与未知，并显示已接受分段数；失败或未知可能已有部分正文被接口接受，先核对 QQ。接口接受不证明已送达或已读。一次确认操作到达失败或未知后不会用同一操作标识重发，重启也不回放历史回复。发送记录可手动刷新。

发送预览和发送记录显示被动回复来源的截止时间。群消息窗口为 5 分钟；浏览网页或查询记录不会延长它。手动发送在进入发送队列时选择同一对话内仍有效的来源，并在后续分段前检查到期时间。没有有效来源时，按钮明确表示“尝试主动发送到 QQ”，是否允许取决于当前机器人的平台权限。

获准且去重通过的普通群消息即使不 @ 机器人，也可以提供回复来源，但前提是 QQ 实际推送该消息。它不因此触发 Agent，也不改变独立的消息保存设置。平台明确拒绝会显示 HTTP 状态、QQ 错误码和原因；网络超时等没有确认的结果保留为未知。旧记录中已经丢失的错误码不会被猜测补写。

## 普通群消息与上下文

QQ 收发正文默认全部保留、不自动清理；需要时在会话设置「消息记录」里手动清空，清空只清记录正文并保留消息标识用于去重，独立于权限与模型背景。未触发消息不会启动模型、不伪造原生 user/message，也不修改宿主 JSONL。实际提问、选入背景、助手回复和工具调用保存在原生 Session。

近期背景默认同时限制最近 10 条、10 分钟和 4,000 字符，按消息标识去重并按已确认的输入推进消费位置。生成期间到达的消息留给后续轮次，`/new` 设置新的背景起点。历史查询工具需要单独授权，开启保存不会自动授予工具。

服务范围与对话开关控制准入，保存开关控制流水，回复开关控制 Agent 触发。停用对话只保留发现身份和原有历史，不保存新正文。仅能使用 QQ 实际推送的消息，本地开关不能获得平台全量群消息权限。

统一记录、保存和迁移的用法见[QQ 会话设置与消息记录](./settings-and-message-records.md)。

## 每群权限与手机命令

全局默认配置用于之后首次接入的群与联系人，每个对话保留独立快照。会话设置编辑备注、接收、Agent 预设、模型、权限、额外提示词、工作目录与斜杠命令；消息记录默认全部保留，可手动清空。

补充提示词和人设保存后，每步组装提示词时读取最新值，即时生效。群聊与私聊补充提示词分别配置，每项最多 80,000 个字符。只有 Agent 预设和工作目录需要新建 Session 才生效。

原生模式沿用 Agent 的实际工具、沙箱与审批规则，自定义模式通过稳定工具标识缩小工具范围。只读不等于只能读取工作区。旧版资源约束和额外审批继续执行，明确确认后才可替换为新的原生规则。子 Agent 与外发守卫不因选择原生模式而失效。

群控制者只能选择所有者允许的模型、预设与权限。群管理员身份不会自动获得控制权。`/model` 保留上下文；`/preset` 在空闲时更换到新 Session；`/new`、`/reset`、`/clear` 开始新会话并保留历史；`/stop` 停止任务并保留原生排队输入。查询与停止使用实际操作者身份。

## 换新与迁移

原生会话默认满 7 天或累计 1,000 条 QQ 消息后，在无运行任务及原生排队输入的后续安全边界自动换新（这是原生会话轮换，与消息记录保留无关）。原生历史保留，本版不提供物理历史删除。QQ 收发正文默认全部保留、可手动清空；发送操作标识与结果继续保留。原生 Session 历史单独保留。

保留原绑定、可靠的 Session 关联、模型偏好、每群策略及旧独立分析 Session。旧群记录仍从只读兼容入口查看，不倒插原生日志，也不重放任务。升级前的旧记录按其历史规则展示，新记录默认全部保留并可手动清空；保留背景使用方式与工具授权。

本版不包含 Mem0、Qdrant、记忆工具或自动提取。旧记忆配置被忽略，旧工具授权被移除；已有后端文件与历史工具结果不删除、不改写。

解绑只清除本机绑定凭据并重载，不删除 Session 历史，也不撤销 QQ 平台侧关系。SDK 入站处理超时不构成原生 Agent 整轮生成的超时上限。

多实例设置独立的绝对 `QQBOT_DATA_DIR`，并隔离 DSH Home、profile 和工作目录。兼容测试与真实 QQ 验证分别报告；离线事件测试不能证明平台授权或实际投递。
