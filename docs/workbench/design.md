# 多机器人 QQ 会话工作台

讨论稿 v0.5 · 2026-11-05 · 第 4–6 项合为一个 PR

你可以在 DSH 管理多个 QQ 机器人。从一个机器人选到开发群或联系人，看到它在 QQ 实际收到和发出的消息。点群或联系人下面的 Session，进入 DSH 原生页面继续工作、查看工具或处理审批。

例如，A 机器人负责项目答疑，B 机器人负责私聊。给 A 的开发群选定项目目录和 Coding Agent 预设后，群里 @ A 的消息进入该群正在接收的 Session。在网页读完原生回答，可以预览并显式发回这个群。切到 B 后，工作台切换到 B 的会话、记录和设置。

## 宽屏从机器人选到具体对话

```text
DSH 左栏 │ 机器人          │ QQ 会话          │ QQ 消息                    │ 设置
QQ 机器人│ + 添加机器人     │ 搜索  全部 群 私   │ 项目开发群 · 研发助手        │ 项目开发群 · 研发助手
         │ ● 研发助手       │ 群聊              │ api-service · 当前接收       │ 概览与接收
         │   设置   已启用   │ ▼ 项目开发群       │ [打开当前 Session] [设置]   │ Agent 与工作区
         │ ○ 私聊助手       │   ● 登录 401 排查  │                            │ 执行权限与工具
         │   设置   已停用   │   ○ 上周发布检查   │ 小林  帮查一下登录接口 401   │ QQ 回复与命令
         │                  │ 私聊              │ 研发助手  已定位原因         │ 消息记录
         │ [收起到头像]     │ ▸ 小王             │ QQ 接口已接受 · 查看原回答   │ [保存更改]
```

四列都在「QQ 会话工作台」标签页内。DSH 的工作区和原生 Session 列表在标签页之外，切换到原生 Session 时仍由宿主管理。桌面端可拖动三处分隔线，也可聚焦分隔线后使用左右方向键。宽度保存于当前浏览器，刷新后恢复。第四列是与消息并排的固定设置栏，可从栏头折叠，第三列随即扩宽。第三列的「会话设置」按钮可重新展开。容器变窄时先使用机器人头像栏，进一步变窄时在会话列表、QQ 消息和设置间切换，恢复宽屏后重新应用已保存的尺寸。

第三列展示机器人实际收到和发出的 QQ 消息。同一发送者的连续消息共用昵称与头像，跨日分隔；平台提供的引用用独立引用块展示。普通附件先显示数量。查看更早的消息时保留阅读位置，新消息可通过底部按钮跳到最新位置。

底部输入框以当前机器人身份直接发送文字到当前群或联系人。Enter 发送，Shift + Enter 换行。网页手动发送会标记来源，不创建 DSH 回合；需要 Agent 工作时，从栏头进入原生 Session。连接中断、暂停或未获准时输入区不可发送。QQ 接口接受只表示接口接收；如果结果未知，先在 QQ 核对，可查询同一笔回执。

### 点击与返回约定

| 操作 | 界面变化 | QQ 接收绑定 |
|---|---|---|
| 左栏点 QQ 机器人 | 打开或切回工作台标签，恢复上次的机器人、对话、展开项、消息位置和设置面板 | 保持原绑定 |
| 点群或联系人正文 | 第三列切换到该对话的 QQ 收发。若会话设置已打开，第四列随选中对话切换 | 保持原绑定 |
| 点群或联系人左边箭头 | 只展开或折叠其 Session 子树 | 保持原绑定 |
| 点任意 Session 子项或「打开当前 Session」 | 打开或激活该 ID 对应的原生 DSH 标签。回到工作台仍是刚才选中的 QQ 对话 | 保持原绑定。打开历史也一样 |
| 点「会话设置」 | 在第四列编辑选中的群或联系人 | 保存按对话字段的生效规则处理 |
| 点机器人齿轮 | 机器人设置替换第 2–4 列，编辑对应账号与机器人级配置。返回后继续此前的对话 | 保存按机器人字段的生效规则处理 |
| 折叠设置 | 宽屏把宽度还给消息列。窄屏返回上一页。再次展开可继续编辑 | 保持原绑定和未保存草稿 |
| 确认「新建 Session」 | 以该对话的配置为起点，可在表单中选工作区和 Agent 预设。成功后在子树标记新的「当前接收」 | 创建成功才切换，失败保留旧绑定 |

有未保存设置时，打开原生 Session 会保留工作台草稿。切到另一个需要替换设置对象的群、联系人或机器人时，提供保存并切换、放弃并切换或取消。

### 第一列选机器人

- **顶部。**「机器人」、添加按钮、收起按钮。展开显示头像、名称和文字状态。收起保留头像、选中态、状态标记和可用键盘打开的菜单。没有账号时直接提供「添加机器人」。
- **账号行。** 名称优先用本地名称，其次用平台返回的名称，最后用 AppID 尾号。头像优先用可验证的平台头像，其次显示首字或 QQ 默认图标。状态分为「已停用」「连接中」「已连接」「重连中」「连接失败」「需重新绑定」。连接失败显示具体原因和重连入口。
- **开关。** 只改变该机器人的启用状态。「已启用」表示希望它运行，「已连接」由网关报告。停用后保留绑定、设置和历史，拦截这台机器人的新 QQ 入站及未发出的投递。重启用只处理之后收到的新事件。
- **机器人设置。** 从账号行齿轮打开，整块替换第 2–4 列，机器人列表继续显示。主机器人的绑定、白名单及现有回复与模型设置都在这里管理。点击「返回会话」恢复之前选中的对话、草稿及布局。以后新增机器人级视图时可复用同一内容区。
- **添加与解绑。** 沿用扫码和手动填 AppID、AppSecret 的入口。绑定完成显示账号身份和接入范围，再允许启用。相同 AppID 导向现有账号。AppSecret 只允许更新。解绑确认页显示机器人名及影响，凭据移除后保留停用账号的历史；同 AppID 重新绑定才能恢复该账号身份。不同 AppID 走新增账号流程。

### 第二列选 QQ 对话或 DSH Session

- 标题显示当前机器人，搜索名称、备注或 OpenID。顶部提供「全部」「群聊」「私聊」，默认按最近一次可显示的 QQ 活动排序。对话名优先用备注，后备为平台有效名称或类型加短标识。群里发言者的昵称单独展示。
- **点击群或联系人行**选中这一 QQ 对话并加载第三列。行内显示最近获准展示的消息、时间，以及「已暂停」「待授权」「未建 Session」等必要状态。点击左边箭头展开或折叠 Session 子项，展开动作保持第三列选择。
- **点击 Session 子项**打开 DSH 原生 Session 页面。当前绑定用「当前接收」标识，暂停或停用时用「已暂停接收」。历史子项显示标题、工作区和最近时间。先显示当前及最近历史，再按页加载。返回工作台恢复上次的机器人、QQ 对话及阅读位置。查看历史保持原接收绑定。
- 「新建 Session」放第三列标题右侧及对话行菜单，打开同一表单。展示当前工作区和预设，默认沿用对话下次设置。选项目与预设后确认，创建成功才更新「当前接收」。归档的当前 Session 提供「恢复原会话」和「新建 Session」。打开历史只使用宿主已有能力，继续在历史页工作的内容留在 DSH。

### 第三列看 QQ 实际收发

- **顶部。** 名称、群或私聊、当前接收状态。次行显示当前 Session 的工作区和预设。提供「打开当前 Session」「新建 Session」「会话设置」。暂停、未绑定、断线或缺宿主能力时，在对应按钮旁解释原因。
- **气泡。** 按时间合并收到的成员消息和机器人实际提交的消息。成员在左，机器人在右。日期分隔，相邻的同一发言者合并头像。引用跳到原消息或显示仍可读的摘要。附件显示类型、名称、大小与可访问状态。收发长文折叠，打开后保留原换行。
- **状态。** 入站显示「未触发」「排队」「已进入 Session」或实际拒绝原因，按需展开。工具过程和文件使用 QQ 投递的折叠行。出站显示「等待发送」「发送中」「QQ 接口已接受」「失败」「结果未知」。流式按一次回复收拢，详情展示分段和终态。QQ 接口回执只证明平台接口接受，客户端可见另行验收。
- **追溯与翻页。** 关联存在时显示「打开原生回合」，定位接口缺失时打开对应 Session。顶部可筛选全部、成员消息、机器人外发和失败记录。支持查找已保存正文、向上分页及「回到最新」。阅读旧消息时保留锚点，用新消息提示替代自动滚动。
- **动作。** 点击当前 QQ Session 的已完成回答下方「发送到 QQ」，在预览核对机器人、群或联系人和原始正文，再确认发送。发送结果出现在同一对话的第三列，记录带有 Session 链接。对话关闭消息保存时，在预览窗口查询结果。第三列输入框可直接以所选机器人发送文字。两处都沿用 QQ 文本发送和回执规则，单条上限为 2,000 字符。若对话允许网页回答自动推送，预览会提示先核对 QQ，避免重复发送。

### 第四列编辑当前范围

第四列的标题带当前对话名。规划中的对话设置分成「概览与接收」「Agent 与工作区」「执行权限与工具」「QQ 回复与命令」「消息记录」。机器人级页面提供「账号和权限」「新会话默认设置」。接入两层配置后，机器人页显示默认值，对话页显示来源、当前生效和新建后生效。

首屏只显示常用项。群 @ 规则仅出现在群聊，私聊流式只出现在私聊，选择自定义工具才展开工具多选。手动文件发送、路径约束等受机器人级权限控制的项目显示有效上限。底部显示本次变更何时生效，并提供「保存更改」「放弃修改」。存在未保存修改时切换账号或对话，需要先保存、放弃或留在当前页。

错误就地显示。默认值不可用时要求改选，正在执行时允许保存下次配置，正在编辑的草稿遇到新版本时保留并显示服务器值。旧记录只有元数据时显示「正文未保存」，平台未推送的内容不计入记录。字段级行为见配置参考。

### 机器人下的扩展入口

建议只展开当前机器人的功能列表。选择机器人默认进入「会话」。群聊、私聊和 Session 继续留在第二列。响应记录等页面占用工作台内容区，页面标题显示账号；从某个对话跳入时带上对话筛选，返回时恢复阅读位置。只有对应能力已经接入的账号才显示入口。

| 入口 | 放置与边界 | 优先级 |
|---|---|---|
| 响应记录 | 第三列的单条状态可展开或跳转，机器人下提供同一数据的跨对话排查视图。按触发来源、已拒绝、已提交、接口接受、失败和未知筛选，可打开相关 QQ 消息或 DSH Session。没有触发证据的记录只展示已知结果。 | 工作台优先提供，复用入站和投递证据，避免重复保存正文 |
| 后台任务 | 机器人下显示由它创建或明确绑定的任务及通知目标；右侧会话设置可查看该对话关联。详情打开 DSH 原生任务或 Session。任务完成后的 QQ 通知由发起者显式指定。 | 后续独立能力，优先复用宿主公开的任务与 Session 接口 |
| 记忆 | 机器人下管理已获授权的记忆空间；对话设置只显示当前关联、读写权限及入口。不同账号之间共享须显式授权。 | 后续可选插件 |
| 用量 | 单轮明细沿用原生 Session。机器人下的页面按该机器人关联的回合聚合，能按对话、模型和时间筛选。只有价格和归因都可核对时才显示费用。 | 有可靠归因后再增加聚合页 |
