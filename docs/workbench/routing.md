# 多机器人工作台设置参考

讨论稿 v0.5 · 2026-11-05

「新会话默认设置」指某个机器人首次建立 QQ 群或私聊配置时采用的模板。首次建立时复制有效值。已有 QQ 对话保留自己的配置，仍可逐项采用机器人当前默认值。给同一个 QQ 对话新建 DSH Session 时，用该对话的下次设置。原生页始终显示本 Session 实际运行的值。

「账号和权限」是该机器人的实时准入上限。对话设置可以缩小它，扩权必须经过拥有对应配置权限的 DSH 操作者。设置页明示机器人默认值、对话覆盖、当前 Session 的值和账号限制来自哪里。显式关闭、清空提示词、采用默认值分别保存。

## 机器人设置的账号和权限

| 设置项 | 页面与编辑方式 | 生效规则 |
|---|---|---|
| 名称、头像 | 本地名称、受支持的头像来源与重置按钮 | 保存后更新账号列表和发送预览。账号标识和历史归属按 AppID。 |
| 启用与连接 | 启用开关、连接状态、最近连接错误、重连 | 即时改变该账号的网关和可提交权限。已发出但尚未回执的操作仍按原账号记账。 |
| AppID 与 AppSecret | AppID 可复制。凭据更新沿用扫码和手动表单，密码框只填新值 | 同 AppID 更新凭据。不同 AppID 新增账号。旧连接在凭据轮换时失去提交资格。 |
| 私聊接入 | 所有人、白名单、关闭 | 按此机器人下的用户 OpenID 校验。白名单为空时拦截。 |
| 群聊接入 | 所有群、白名单、关闭 | 按群 OpenID 校验。开放接入与是否需要 @ 分别判断。 |
| 配对和名单 | 各名单沿用 #113 的配对码、OpenID 添加、撤销、导入导出及版本校验 | 配对批次与撤销归当前机器人和用途。导出保留 OpenID 与备注。账号切换后旧对话框不提交到新账号。 |
| QQ 斜杠命令授权 | 所有获准接入的发言者、命令白名单、关闭 | 延续 #113。命令白名单按发言者身份判断，群白名单只证明群获准接入。对话里的命令开关还需开启。关闭的斜杠输入收到明确反馈，审批和提问回执仍走既有独立检查。 |
| 文件外发限制 | 折叠在「高级权限」。显示路径约束、额外允许目录 | 复用现有路径校验。新账号保持路径限制开启，额外目录只由账号设置授权。对话侧只能缩小范围。 |
| 诊断 | 折叠在「连接诊断」。连接状态、最近平台错误、测试连接、调试输出开关 | 测试连接用于核对连接和凭据。状态详情剔除凭据和正文。调试设置只影响当前机器人。 |

新绑机器人的接入范围在向导中显式确认，建议预选群聊、私聊白名单。命令初始选项沿用 #113 的「所有获准接入的发言者」。从单账号迁移时复制原接入模式、名单和命令模式。白名单选项使用 QQ 平台 OpenID，并说明它与 QQ 号的区别。

## 从旧 456 延续的设置

机器人设置保留「账号和权限」与「新会话默认设置」两页。默认页按群聊和私聊编辑，同一字段定义也用于会话设置。QQ 对话首次建立时保存一份默认值快照，已有对话可显式采用机器人当前默认。

| 位置 | 从旧 456 延续或从上游保留的能力 |
|---|---|
| 对话独有 | 接收开关、备注、保存 QQ 消息及已有记录管理。工作区与 Agent 预设通过「新建 Session」变更。当前值来自原生 Session。 |
| 默认与会话共用 | 群／私聊补充提示词、执行权限、基于实际工具目录的自定义多选。工具范围受 DSH 原生权限和审批约束。模型与推理强度在机器人默认页设置，当前 Session 沿用原生输入框。 |
| QQ 回复 | 保留上游仅 @ 时回复、私聊流式输出 `streaming`、显示成功工具调用结果 `showToolResults`、自动发送交付文件 `sendFile.sendPresentedFiles`。群聊沿用静态路径，工具结果的可见性与工具执行权限分别控制。 |
| 账号上限 | 名单、命令访问模式及文件路径约束归机器人账号。会话覆盖只在账号准入范围内生效。 |

实现先完成「选择工作区和预设并新建」，再接默认模板与会话覆盖。新建失败保留当前接收映射。消息流水使用插件自己的展示账本，从启用后开始记录。关闭开关保留已有记录；第一笔只读流水没有引入自动删除或手动清理，`historyLimit` 继续只控制群上下文缓存。

## 机器人默认值与对话设置复用同一组字段

机器人页可以在「群聊」「私聊」之间切换。对话页只展示适用于当前类型的项。下表的默认值指新绑机器人建议。升级时以原来实际生效的配置为准。

| 分组与字段 | 新绑机器人建议 | 对话覆盖何时生效 |
|---|---|---|
| Agent 预设 | 选择已有 DSH preset，也可采用 DSH 默认。详情展示预设所需能力 | 对话页同时显示当前预设和下次预设。开始后的 Session 通过新建使用新预设。 |
| 工作区与目录 | 选已登记的 DSH 工作区，或明确使用插件专用目录 | 新 Session 创建时生效。展示工作区名和实际目录。路径不可用时保留原绑定并提示修复。 |
| 模型 | 采用 DSH 默认，或选择提供商与模型 | QQ 对话配置为此对话的下次默认。应用到当前 Session 时复用经验证的会话级接口。界面同时读原生当前值。 |
| 推理强度 | 采用模型默认。仅列当前模型支持的档位 | 下一次请求生效，运行中的请求保持原值。换模型后校验强度，失效时提示并可重选。 |
| 补充提示词 | 分群聊与私聊，默认留空 | 只影响该类型的下一轮，通过现有系统提示词段注入。当前对话允许显式清空。 |
| 执行权限 | 仅可查看。可选宿主支持的工作区内修改、完全权限及对应审批模式 | 实际执行受 DSH 沙箱与审批控制。对已开始的 Session，能安全同步的模式按已验证的原生接口更新。需要重建或放宽权限时明确预览生效时机。 |
| 可用工具 | 默认沿用已装配的预设工具，并受原生权限限制。可选无工具、只允许所选工具 | 可按名称和类别搜索、多选。选择项只能收窄实际权限。收紧立即挡住后续调用，放宽在空闲后的下一轮生效。无法可靠约束的工具或模式显示不可用及原因。 |
| 处理方式 | 群聊仅 @ 时触发，私聊按现有触发条件处理 | 下一条消息生效。可见性来自官方 QQ 网关实际推送，触发设置本身无法改变平台推送范围。 |
| 斜杠命令 | 默认允许获准发言者使用 | 本地开关在下一条 QQ 命令生效。有效权限取账号命令模式、接入许可及该开关的交集。 |
| 流式输出 | 私聊开启，群聊显示平台路径为分段或静态 | 下一轮开始使用新值。已发出的流式帧和最终发送状态按原操作追踪。 |
| 工具过程 | 关闭成功结果预览，沿用现有错误提示规则 | 下一轮改变 QQ 端工具预览。DSH 原生工具记录按宿主展示。 |
| 网页回答自动推送 | 新绑建议关闭，需要时开启。旧账号保留原来的关闭、仅私聊或包含群聊的有效行为 | 只影响该对话的纯网页回合。混合来源按 #118 判定。显式发送仍需单次确认。 |
| 自动发送交付文件 | 继承现有配置，显示开关与会话实际可发送路径 | 下一轮生效，仍受账号路径限制、原生权限及发送来源约束。手动工具发送和自动交付物分别显示。 |
| 接收附件 | 继承现有媒体开关和账号上限 | 下一条消息生效。对话可关闭下载，或降低大小上限。禁用时保留允许的附件摘要。 |
| QQ 正文记录 | 沿用旧 456 的产品默认值，对已授权的新对话开启。绑定时展示记录开关和保存范围 | 从下一条符合准入的事件开始。关闭后现有记录按原有规则管理。原生 Session 日志由 DSH 保存。已有 QQ 记录及明确留存策略延续原值。 |

「采用机器人当前默认」支持单字段和整组。提交前列出旧值、新值和生效时间。账号模板改动不批量改写现有群、私聊。DSH 预设里的工具数量不等于该 QQ 对话的有效工具数。

已查宿主的 `session.selectModel` 同时保存 DSH 默认模型。设置栏里的「保存更改」只写 QQ 对话偏好。「应用到当前」走会话级能力，先验证它不会更新 DSH 默认或意外切换 Session。若只有 #118 的 `/model` 接续路径可用，界面预告生成接续 Session，或仅提供「下次 Session 生效」。当前工作区和预设都从原生 Session 读取。对话侧的字段只写自己拥有的配置。 [DSH 模型选择](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/api/session-controller/src/commands.ts#L144-L168) · [DSH 预设切换边界](https://github.com/deepseek-ai/deepseek-harness/blob/f3803c96974ad4a94195fb97e5c637e9c2a3afe3/packages/preset/agent-preset-registry/src/index.ts#L357-L376)

## 主动推送现状与工作台入口

- 上游与 #118 已支持把绑定 QQ 的 DSH Session 中纯网页／桌面回合的最终回答发到对应群或私聊。`proactiveDelivery.externalTurns` 支持 `off/c2c/all`，当前默认仅私聊。宿主服务回合（例如在该绑定 Session 内执行的定时任务）走独立规则，网页推送关闭并不等于任务通知关闭。#118 对混入网页输入的 QQ 回合停止后续自动投递，并在提交前复查账号与准入。 [现有配置](https://github.com/tencent-connect/dsh-qqbot/blob/0ddf232ef24a6e38b8ebd73c68b360c39f87adf7/src/config.ts#L189-L194) · [#118 来源判断](https://github.com/gosomea/dsh-qqbot/blob/79693845a600d2e023cda917d89d5e9240690dcc/src/transport/turn-tracker.ts#L151-L196)
- QQ 协议层将不携带回复 ID 的主动发送、带 `msg_id/event_id` 的被动回复以及 `is_wakeup` 互动召回分开。插件部分静态路径会在缺少可用回复 ID 时尝试主动发送；主动请求仍受 QQ 的接收开关、权限与限流约束。设置页显示实际选择的路径和平台错误，未知结果保持可核对状态。 [回复目标](https://github.com/gosomea/dsh-qqbot/blob/79693845a600d2e023cda917d89d5e9240690dcc/src/transport/reply-target.ts#L24-L56) · [QQ 官方规则](https://bot.q.qq.com/wiki/develop/api-v2/server-inter/message/overview.html)
- 手动代发、网页回答自动推送、任务完成通知分别授权。将来增加代发时，固定机器人与对话，明确显示是发送新消息还是回复某条消息，复用投递防重与回执。Orange Bot 的代发不唤醒 Agent，但它的官方 QQ 路径仍可能带上近期回复 ID。旁听是另一套触发规则。 [Orange Bot 手动发送](https://github.com/std-microblock/orange-bot/blob/c6160a81ccabc0ed29f76d17f6a4f4a31f67a391/packages/dsh-plugin-orange/src/web.ts#L269-L277) · [Orange Bot 路由](https://github.com/std-microblock/orange-bot/blob/c6160a81ccabc0ed29f76d17f6a4f4a31f67a391/packages/dsh-plugin-orange/src/satori.ts#L427-L453)

## 对话独有项与已有高级字段

| 字段 | 放置位置 | 行为 |
|---|---|---|
| QQ 备注、OpenID | 概览与接收 | 备注保存后更新导航和发送预览，OpenID 只读可复制。 |
| 接收此对话 | 概览与接收 | 即时暂停该对话的 QQ 入站、未领取的工作及后续自动和手动外发。已经开始的 DSH 工作可在原生页停止。 |
| 当前 Session、下次配置、历史 | 概览与 Agent 卡片 | 当前 Session 只读显示并可打开。新建成功才改变接收绑定。历史条目从第二列访问。 |
| 正文记录与清理 | 消息记录 | 显示记录启用时间、可用数量及明确配置的留存方式。清理需确认并且只作用于当前 QQ 对话的记录正文。防重凭证与 DSH 历史独立。 |
| 群历史缓存条数 `historyLimit` | 新会话默认设置的高级项，群聊可覆盖 | 控制注入的短期群上下文，与 QQ 时间线正文记录、Session 换新、正文留存分别处理。 |
| `textChunkLimit`、`sendFile.maxFiles` | 高级投递默认值 | 延续既有默认和已设值。按下一次发送或下一轮应用，遵守平台及账号上限。 |
| `media.maxMB`、`media.ttlHours` | 高级媒体默认值 | 下载大小在接收时检查。文件缓存 TTL 不用于消息历史。缩短 TTL 时避免删除正在使用的文件。 |
| `vision.enabled`、`provider`、`model`、`defaultPrompt`、`maxBytes`、`maxTokens`、`timeoutMs` | 高级媒体配置 | 与主 Agent 模型分别展示。仅在已装配并授权视觉工具时有效。保留既有配置；首版只把经过验证的字段暴露给对话覆盖。 |
| `maxQueue`、`processingTimeoutMs`、`askTimeoutMs`、`sessionIdleTimeout` | 机器人运行诊断的高级配置 | 继续支持旧配置。首版提供有效值和当前队列状态。入队、处理超时、待答超时、空闲回收各按现有用途。空闲回收不等于新建 Session。 |

首版保证机器人默认表单和对话表单在常用项一致。高级运行和诊断字段归账号，含已有 `debug`。权限上限、凭据和名单从账号层读取。所有保存请求按目标和版本校验，备注或提示词修改只提交对应字段。配置缺失与首次打开旧对话使用实际服务端基线。真正的并发冲突返回 409 并保留草稿。
